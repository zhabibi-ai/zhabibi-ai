# Natiq Studio — راهنمای سریع

- ورودی‌ها: صوت + (متن خام یا متن اصلاح‌شده)؛ ایرادات اختیاری (فایل یا چسباندن).
- «تحلیل» صوت را یک‌بار پردازش می‌کند. بعد از آن هر متن/ایرادی را عوض کنید، دکمه‌ی «اعمال» را بزنید.
- «ویرایش متن»: نوشتن/اصلاح در همین برنامه ← «ذخیره‌ی ویرایش» (به‌عنوان متن اصلاح‌شده ثبت و دوباره تطبیق می‌شود).
- «رنگ هایلایت‌ها»: رنگ و شفافیت ایرادات، کلمه‌ی در حال پخش و جستجو (ذخیره می‌شود).
- «ریست»: همه چیز پاک می‌شود برای فایل بعدی (تنظیمات مدل حفظ می‌شود).
- کلیدها: Space پخش/توقف | Ctrl+Space همه‌جا | Alt+←/→ ‑۵/+۵ ثانیه | Ctrl+Click پخش از کلمه | Alt+Click یا F2 ثبت لنگر دستی.
- قالب ایرادات (یک خط برای هر ایراد): `1. «عبارت» | پیشنهاد: ... | وضعیت: ...` — دکمه‌ی «قالب Gemini» پرامپت کامل را کپی می‌کند؛ «پذیرش و جایگزینی» عبارت پیشنهادی را در متن می‌نشاند (با «واگرد» برمی‌گردد).
